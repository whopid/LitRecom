# LitRecom — адаптивный бот для подбора книг

## О проекте

**LitRecom** — это Telegram-бот для поиска и персонализированного подбора литературных произведений. Проект разработан в рамках выпускной квалификационной работы на тему «Адаптивный бот для подбора тематической литературы с использованием технологий онлайн-мессенджеров».

Основная задача проекта — упростить поиск книг и помочь пользователям находить произведения с учётом их интересов и предпочтений.

Система использует гибридный подход к рекомендациям, объединяющий анализ пользовательских предпочтений и популярности жанров. Информация о книгах получается из внешнего источника — Google Books API, а данные о пользователях и их взаимодействии с системой сохраняются в базе данных PostgreSQL.

## Возможности

- **Анкетирование пользователя.** Выбор любимых жанров при первом взаимодействии с ботом.
- **Персонализированные рекомендации.** Подбор книг с учётом выбранных жанров, пользовательских оценок и популярности жанров.
- **Оценка рекомендаций.** Возможность поставить лайк или дизлайк предложенной книге.
- **Случайная книга.** Получение случайного литературного произведения.
- **Поиск книг.** Поиск произведений по названию с использованием Google Books API.
- **Настройки.** Доступ к настройкам взаимодействия с ботом.
- **REST API.** Серверная часть предоставляет методы для работы с пользователями, жанрами, предпочтениями, оценками и рекомендациями.
- **Документация API.** FastAPI автоматически формирует интерактивную документацию для проверки доступных запросов.

## Архитектура проекта

Система состоит из нескольких взаимодействующих компонентов:

1. **Telegram-бот** — пользовательский интерфейс для поиска книг, получения рекомендаций и отправки оценок.
2. **Backend** — обработка запросов, выполнение алгоритма рекомендаций и взаимодействие с данными.
3. **База данных PostgreSQL** — хранение пользователей, жанров, предпочтений, оценок и истории рекомендаций.
4. **Google Books API** — внешний источник сведений о литературных произведениях.

При формировании рекомендаций система получает профиль предпочтений пользователя, анализирует историю оценок и популярность жанров, после чего выполняет поиск подходящих книг во внешнем источнике.

## Алгоритм рекомендаций

В основе рекомендательной системы лежит взвешенная модель, которая учитывает несколько факторов:

- предпочтения пользователя, заданные при прохождении анкеты;
- положительные оценки ранее предложенных книг;
- популярность жанров среди пользователей системы;
- историю ранее выданных рекомендаций.

Для оценки релевантности жанра используется комбинация пользовательского веса и показателя популярности:

`Score = α × Pref + β × Pop`

где:

- `Pref` — показатель соответствия жанра интересам пользователя;
- `Pop` — показатель популярности жанра;
- `α` и `β` — весовые коэффициенты.

Книги, уже показанные пользователю, исключаются из повторной выдачи. Полученные кандидаты ранжируются, после чего выбирается заданное количество рекомендаций.

## Требования

Для запуска проекта необходимы:

- Python 3.13 или совместимая версия;
- PostgreSQL;
- Telegram-бот, зарегистрированный через [@BotFather](https://t.me/BotFather);
- API-ключ Google Books.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone git@github.com:whopid/LitRecom.git
cd LitRecom
```

### 2. Создание виртуального окружения

macOS / Linux:

```bash
python3 -m venv venv
source venv/bin/activate
```

Windows:

```bash
python -m venv venv
venv\Scripts\activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Создайте файл `.env` в соответствии с конфигурацией приложения. Пример:

```dotenv
BOT_TOKEN=your_telegram_bot_token
DATABASE_URL=postgresql+asyncpg://username:password@localhost:5432/litrecom
GOOGLE_BOOKS_API_KEY=your_google_books_api_key
```

### 5. Подготовка базы данных

Создайте базу данных PostgreSQL и настройте подключение к ней.


### 6. Запуск приложения

```bash
python main.py
```

## Хранение данных

В PostgreSQL сохраняются структурированные данные, необходимые для работы рекомендательной системы:

- сведения о пользователях и их Telegram-идентификаторах;
- жанры литературных произведений;
- пользовательские предпочтения;
- оценки книг;
- история выданных рекомендаций.

Основная информация о книгах получается из Google Books API. Поэтому полное описание каждого произведения не обязательно хранить в локальной базе данных: при необходимости сведения можно получать из внешнего источника по идентификатору книги.

## Ограничения

- Набор доступных книг зависит от содержимого Google Books API.
- Качество персонализации зависит от полноты пользовательского профиля и накопленных оценок.
- Для новых пользователей используется начальный профиль предпочтений, поскольку история взаимодействий ещё отсутствует.
- Доступность сведений о жанрах, обложках и описаниях зависит от данных, предоставляемых внешним API.

## Перспективы развития

В дальнейшем проект можно расширить за счёт использования текстовых признаков книг, более сложных методов ранжирования, кэширования ответов внешнего API и автоматизированного тестирования. Также возможно улучшение адаптивности алгоритма за счёт анализа изменений пользовательских интересов во времени.
